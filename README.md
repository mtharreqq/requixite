# Requixite

> **Precise. Exquisite. Requisite.**
> Independent product and web studio by Tharreq.

Portfolio for polishing vibecoded apps: [requixite.my.id](https://requixite.my.id). English at `/`, Bahasa Indonesia at `/id`.

## Stack

Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS v4, Framer Motion, Lenis, Radix/shadcn, Vercel Analytics. Fully static.

## Run

```bash
npm install
npm run dev
```

## Content

- Copy: `lib/portfolio-copy.ts` (site) and `lib/case-study-copy.ts` (case studies), one object per language.
- Pages: `app/(english)` and `app/(indonesian)/id`; see `CLAUDE.md` for the layout.
- AI tool logo sources and licenses: `public/ai-logos/SOURCES.md`.

Motion follows the RantAI landing page; the interface uses no monospace outside terminal surfaces (see `AGENTS.md`).
